# 나두 PDF 변환기

개인 PC 브라우저에서만 쓰는 PDF 도구입니다. 파일은 서버로 올라가지 않고, 이 페이지 안에서 처리됩니다.

## 기능

- PDF 합치기 (드래그 앤 드롭, 순서 변경)
- PDF 나누기 (페이지별 PDF를 ZIP 한 개로 저장)
- 페이지 추출 (`1-3, 5` 형식)
- 페이지 회전 (90 / 180 / 270도)
- 이미지 → PDF (JPG, PNG)

## 제한

- 파일 1개 80MB
- 합치기·이미지 변환 합계 150MB

## 사용

GitHub에 올리면 Vercel이 이 `index.html`을 배포합니다. 로컬에서는 파일을 브라우저로 열어도 됩니다.
