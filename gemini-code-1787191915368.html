💡 Stirling-PDF란 무엇이고 어떻게 만들었나?

1. Stirling-PDF 도입 배경

문서 작업을 하다 보면 PDF 합치기, 용량 줄이기, 이미지 변환 등 다양한 기능이 필요합니다. 하지만 일반 무료 웹사이트들은 중요한 사내 문서나 개인정보가 외부 서버로 유출될 위험이 있습니다. 오픈소스인 Stirling-PDF는 모든 처리가 내 서버 안에서 이루어지므로 보안성이 완벽합니다.

2. 서버 비용 0원으로 배포하는 아키텍처

이 웹사이트는 프론트엔드 UI와 광고 영역을 Vercel에 배포하고, 실제 무거운 PDF 처리 엔진은 무료 클라우드 호스팅인 Render(Docker)에 올려 하이브리드 형태로 구성했습니다. 덕분에 서버 유지 비용이 전혀 들지 않습니다.

Vercel (UI & 광고 영역) <--- API / iframe ---> Render (Stirling-PDF 엔진)

3. 나만의 PDF 웹서비스 구축 팁

누구나 깃허브 레포지토리에 코드를 올리고 Vercel과 연동하면 5분 만에 자신만의 도메인으로 PDF 포털을 오픈할 수 있습니다. 본 페이지처럼 광고 지면을 커스텀하여 부가적인 수익 파이프라인으로 확장하는 것도 가능합니다.
